# 论文写作与投稿

## 1. IMRaD 骨架（临床研究）

- **Introduction**（3 段）：疾病/临床问题负担 → 现有证据现状与缺口 → 本研究目的与假设。
  最后一句明确 primary objective。
- **Methods**：设计、受试者（入排）、干预（参数/对照/校准）、结局（主要/次要/探索性 +
  测量方法 + 时点）、随机化与盲法、样本量、统计分析（estimand + 分析集 + 缺失 +
  多重性）、伦理与注册号。**方法必须可复现** —— 按 SPIRIT 条目写。
- **Results**：流程图 → 基线表（Table 1，按随机分组，不写 p 值）→ 主要终点
  （调整后差 + 95%CI + p）→ 次要终点（按预设顺序）→ 安全性（AE 表）。
- **Discussion**：主要发现 1 段 → 与既往证据比较（解释一致/差异）→ 机制与解释 →
  局限（样本量、中心数、盲法、剂量、随访、外部效度）→ 临床意义与未来研究 →
  结论（不夸大）。
- 报告规范对应表：

| 设计 | 规范 |
| --- | --- |
| RCT | CONSORT（+ 摘要规范） |
| 观察性 | STROBE |
| 系统综述/Meta | PRISMA 2020（检索写 PRISMA-S） |
| 研究方案 | SPIRIT |
| 诊断/预后/质量改进 | STARD / TRIPOD / SQUIRE |

投稿时附对应 checklist 与流程图。

## 2. 标题与摘要

- 标题：设计 + 人群 + 干预 + 主要结局（可加注册号）。避免「显著改善」这类结论词；
  RCT 注明 randomized / sham-controlled。
- 结构化摘要五步：背景 1 句 → 目的 1 句 → 方法 2–3 句 → 结果 2–3 句（关键数字：
  组间差、95%CI、p、AE）→ 结论 1 句（限定在证据内）。
- 摘要数字必须与正文一致；不引文献；缩写首次定义；字数按目标期刊。
- 关键词 5–8 个，优先 MeSH 词。

## 3. 期刊选择（先定 3 档）

看：scope 是否收该主题、近期是否发过类似文章、影响因子/分区、审稿周期、OA 费用、
字数/图表限制、是否要求注册、报告规范要求、数据共享与 AI 使用声明要求。
按「冲刺 / 稳妥 / 保底」各选 1–2 个，先问清导师与单位的毕业/评职要求。
投稿前逐项核对期刊 author guidelines 与 submission checklist。

## 4. Cover letter（半页）

一句题目 + 一句主要发现（带关键数字）+ 一句为什么适合该刊 + 声明（未一稿多投、
全体作者同意、无利益冲突、注册号、伦理批号）。不要复述摘要。

## 5. 审稿回复

- 逐条编号：`Reviewer comment` → `Response` → `Change in manuscript (Page/Line)`。
- 态度：感谢 + 直接回答 + 改了什么；不改就给理由与证据。
- 新增分析要报告方法、结果与局限；不得只挑有利结果。
- 大改后附 clean 版 + tracked-changes 版，逐条核对「已改/未改」。

## 6. 参考文献与写作工具

- 医学期刊多用 Vancouver；用 `pubmed cite --pmids ...` 生成初稿，再按目标期刊调格式。
- 核对：`pubmed verify --file 稿件.md`，确保没有假引用。
- 稿件用 Markdown 写 → `md2docx` 转 .docx 交付（源文件保留 .md）。
- 图：`figures`（森林图/柱状/折线，SVG）；正式投稿图建议在 PC 端重绘（≥300 dpi）。
- 语言：中文稿术语保留英文；英文稿注意时态（Methods 过去时、结论现在时）。

## 7. 学术规范（红线）

- 不编造数据/文献/作者；不篡改结果；不选择性报告。
- 禁止一稿多投与拆分发表（salami slicing）；预注册与发表一致。
- AI 使用按期刊/学校要求声明；AI 不得列为作者。
- 数据与代码尽量共享（FAIR）；患者隐私脱敏。
- 作者顺序按贡献（CRediT），通讯作者与单位署名按单位规定。
