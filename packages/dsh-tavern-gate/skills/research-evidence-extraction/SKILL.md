# 证据提取、偏倚风险与证据表

## 1. 证据卡字段（固定，不要增删）

1. 编号（PMID/DOI）
2. 研究类型（人体 RCT / 人体观察 / 动物 / 系统综述 / 叙述性综述，按原文写）
3. 对象（物种或人群、样本量/分组、年龄性别等、诊断/纳入标准）
4. 干预参数（设备、波长 nm、功率、功率密度、能量密度、部位与面积、单次时长、频次、疗程）
5. 对照设置（假干预实现方式、盲法层级）
6. 结局（主要/次要、测量方法、时间点）
7. 关键结果（只抄原文数值：组间差、p、95%CI、效应量；没写就「未报告数值」）
8. 偏倚风险要点（随机序列、分配隐藏、盲法、样本量计算、脱落、利益冲突）
9. 可借鉴 / 不可外推（参数、对照、结局、随访窗口 vs 物种/部位/人群差异）
10. 原文引证（1–2 条关键原句 + 小节位置）

## 2. 提取纪律（硬规则）

- 任何数字必须原文可查；查不到写「未报告」，**禁止推测或用常识补全**。
- 动物/人体、牙科/颌骨与四肢骨、体外与体内严格区分。
- 摘要与全文冲突：以全文为准，并记录冲突。
- 一篇一篇独立提取，不跨文献比较；合成放到证据表阶段。
- 系统综述要额外记录：检索库/日期、纳排标准、纳入研究数、异质性 I²、效应模型、
  发表偏倚评估。
- 扫描件无文本层：说「无文本层，需 OCR」，不要猜。
- 每篇标注「已核对原文 / 仅读摘要」。

## 3. 偏倚风险评估

- **人体 RCT：RoB 2（5 域）** 随机化过程 / 偏离既定干预 / 缺失结局数据 / 结局测量 /
  结果选择性报告。每域给 低风险 / 有一定风险 / 高风险 + 一句依据。
- **非随机干预：ROBINS-I（7 域）** 混杂、选择、干预分类、偏离、缺失、测量、选择性报告。
- **动物：SYRCLE（10 条）** 随机分配、基线、分配隐藏、饲养随机化、盲法、结局评估盲法、
  缺失数据、选择性报告、其他。**动物证据必须标 SYRCLE，不能写「RoB 2 低风险」。**
- **系统综述：AMSTAR 2 或 ROBIS**（登记、检索全面性、筛选、提取、偏倚评估、合成、
  发表偏倚、利益冲突）。

## 4. GRADE 分级

- 起始等级：RCT 证据体=高；观察性=低；动物/体外=很低（一般不进入临床推荐）。
- 降级 5 因素：偏倚风险、不一致性、间接性、不精确性、发表偏倚。
- 升级 3 因素（观察性）：效应量大、剂量-反应、混杂方向会低估效应。
- 输出：每个结局「证据确定性 高/中/低/很低 + 一句话理由」，再给推荐强度（强/弱/无）。
- 证据不足时写「证据缺口」，不要写成「证据支持」。

## 5. 证据表维护

- 源文件用 Markdown 或 CSV；要给合作者看 Excel 时 `xlsx_tools csv2xlsx`。
- 固定列建议：编号｜类型｜人群/物种｜n｜干预参数｜对照｜主要结局｜结果数值｜偏倚风险｜
  可借鉴｜不可外推｜核对状态。
- 剂量/参数汇总单独一张表，写方案附录时直接引。

## 6. 批量读文献（subagent）

- 输入：一次 5–8 篇全文（PDF 先 `pdf_tools batch` 转 txt），附固定字段任务书。
- 提示词模板：
  > 你是循证医学方法学助手。按以下固定字段逐篇提取（不要跨文献比较，不要推测）；
  > 字段原文没有就写「未报告」。输出先汇总表再逐篇证据卡，中文，术语保留英文，
  > 数字必须原文可查。
- 成本控制：每批 ≤8 篇；只回证据卡与汇总表，不复述全文；两批之间主 Agent 抽查 2 篇
  核对原文。

## 7. 证据合成

- 先判断能否合并（人群、干预参数、对照、结局、时点是否同质）；不能合并就按
  参数/人群/结局分层做叙述性总结。
- 能合并：效应量 + 95%CI + I² + 模型；敏感性分析（去高偏倚、去小样本）。
- `figures forest` 可画森林图（CSV 列 study,est,lo,hi[,weight]；`--pooled` 逆方差法仅示意，
  正式 Meta 建议在 PC 用 R metafor / RevMan 复核）。
- **禁止**把不同量纲的效应量（SMD、MD、OR）混在一张图或一句话里比较。
