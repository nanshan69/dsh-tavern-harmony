# 学术润色（去 AI 腔，中英双语）

本技能把 AI 辅助写出的学术文本改得更像真实学者的定稿：**准确、克制、具体、每个论断有出处**。
它只改表达，不改内容。它不用于规避 AI 使用披露；投稿时仍按目标期刊/基金委的披露政策执行。

## 一、核心原则（先看这五条）

1. **只改表达，不改内容。** 数字、单位、统计量（p、95%CI、效应量、样本量）、图表号、引用、
   公式、符号、专有名词、结论方向，一律原样保留。发现疑似错误只标注、不擅自改。
2. **学术的“人味”是准确和克制，不是口语化。** 不要加金句、表情、感慨、第一人称抒情。
3. **先审后改。** 先产出问题清单（位置+类型+建议），再动手改写；避免边读边改导致逻辑漂移。
4. **不过度纠偏。** 有证据限定的模糊语（提示/提示可能/与……一致）、合适的被动语态、
   学科惯例（方法学被动、我们/本研究、定义与公式）要保留；删空泛，不是删所有修饰。
5. **不编、不删、不升级证据。** 不编数据/文献/前期结果；不把“相关”改“因果”、不把动物证据改人体证据、
   不把“提示”改“证明”；拿不准就列“待作者确认”，不替作者做判断。

## 二、工作流（审 → 改 → 核 → 报）

**0. 读上下文。** 确认文档类型（论文/摘要/综述/方案/标书/审稿回复）、目标期刊或基金、
语言（中文/英文）、作者既往文风样本；同目录若有术语表、模板、投稿须知，先读。

**1. 审计（不先改）。** 逐段列问题，形成表：

| 位置 | 原句摘录 | 问题类型 | 证据状态 | 建议改法 |
|---|---|---|---|---|

问题类型用本技能第三节的编号（如 C1 意义拔高、C4 抽象动词、E2 过度声称）。

**2. 改写。** 按段落改，保持原结构、原篇幅、原编号；一个意思一句，长句拆开；
不改变段落顺序与论证链。**每改完一段，回读该段的数字/引用是否仍一一对应。**

**3. 主张-证据核对（最重要）。** 对每个实证论断问两句：
（a）它的结论句有没有数字/图表/引用支撑？
（b）动词强度是否超过证据强度？（证明 > 显示 > 提示 > 可能）
不满足就加证据指针或降级动词，见第五节。

**4. 自检 + 报告。** 交付前逐项过第六节清单；输出格式见第九节。

时间紧的快速模式：只做“审计表 + 改最差的 1–2 段 + 自检”，别整篇重写。

## 三、中文 AI 腔清单（按出现频率排序）

**C1 意义拔高 / 宏大趋势。** 至关重要的、发挥了关键作用、凸显了重要性、为……奠定了基础、
标志着……的转变、不断演变的格局。
→ 删掉宣示，直接说“做了什么、发现了什么、对谁有用”。

**C2 公式化起笔。** “近年来，X 受到越来越多的关注”“随着 X 的快速发展”“尽管取得了进展，但……”。
→ 用具体事实/具体缺口开头：先给出现状或矛盾，再给本研究要补的洞。

**C3 段末套路总结。** 综上所述、由此可见、不难发现、这提示我们、此案例印证了/揭示了。
→ 多数直接删；需要过渡时用自然的转折或递进句，不必每段都“总结+点题”。

**C4 抽象动词制造虚假深度。** 体现了、彰显了、凸显了、反映了、促进了、展示了（后面接的往往是空话）。
→ 换成具体动作或直接删除；一句里出现两个以上这类词基本可判定为凑深度。

**C5 模板化问题陈述。** 面临的核心问题是、核心挑战在于、主要矛盾体现在、亟需解决。
→ 用具体现象和后果说明“问题是什么”，不用抽象标签。

**C6 推销式/广告化语言。** 充满活力、丰富（比喻义）、深刻的、开创性的（比喻义）、令人叹为观止、极大地。
→ 换中性、可核实的描述；“显著”必须有统计检验支撑。

**C7 模糊归因。** 专家认为、研究表明、业内普遍认为、一些学者指出（而无引用）。
→ 有引用就保留引用信息；没有出处的套话删除或改成直接陈述。**绝不编造引用**。

**C8 万能展望段。** 尽管面临挑战、未来展望、前景广阔、为……提供了新思路、意义深远。
→ 只保留有具体内容、能落到下一步研究/临床决策的表述；泛泛升华删掉。

**C9 中文 AI 高频词。** 深刻揭示了→说明/表明；具有重要意义→直接说意义；不可或缺→必要/关键；
至关重要的→关键的；综合运用→结合使用；深入探讨→分析/讨论；系统梳理→梳理/归纳；
提供了理论支撑→提供理论依据；有效解决了→解决了/缓解了（按证据强度）；充分说明→说明；
值得注意的是/需要指出的是→多数可删；凸显/彰显→说明/显示；错综复杂→复杂/多层次。
**命中不等于必须换**：语境自然、准确、必要时保留。

**C10 回避“是/有”。** 作为……的重要载体、扮演着……的角色、充当着……的功能、作为……而存在。
→ 能用“是/有”就说“是/有”。

**C11 三元对称 / 对仗排比 / 否定排比。** “首先/其次/再次”三连、“从 X 角度/从 Y 角度/从 Z 角度”、
四项四字动宾连排、“不仅仅是……更是……”。
→ 打破对称，按论述重点分配篇幅；只保留最核心一项展开。

**C12 刻意同义替换。** 同一概念为避免重复而不断换词（如 PBM / 光生物调节 / 低强度光疗混用）。
→ 学术写作术语必须前后一致；用简称约定（首次全称+缩写）后统一。

**C13 虚假范围。** “从 X 到 Y”两端不在同一维度。
→ 改为具体列举，或保证两端可比较。

**C14 排版滥用。** 正文破折号一段超过 2 处、强调性粗体、内联标题的纵向列表、表情符号。
→ 破折号改逗号/括号/分句；删强调粗体；列表改连贯段落；表情全删。

**C15 填充与过度对冲。** “为了实现这一目标”“由于……这一事实”“在当前这个时间节点”
“具有处理……的能力”“值得注意的是，数据显示”。
→ 改为“为此”“因为”“目前”“可以处理”“数据显示”。对冲词叠加（可能或许在一定程度上）
只留一个，但**有实际限定作用的审慎表述必须保留**。

**C16 聊天机器人残留。** 希望对你有帮助、当然！、这里是一份……、截至某日期（作为免责话术）、
过度谄媚的评价。
→ 全删。其中“截至/截至检索日期”若是在说明检索时间范围，属于正常方法学表述，保留并写清检索日期。

## 四、必须保留（不当作 AI 腔处理）

- **有证据的学术审慎**：提示、可能、与……一致、我们假设、尚不能排除——这是严谨，不是啰嗦。
- **方法学被动**：样本按……处理、指标由……测定（施动者不重要时被动更合适）。
- **“我们/本研究/本文”**：正常学术人称，不必刻意回避；也不宜每句都用。
- **定义、公式、符号、命名方法/指标、量表名、统计量**：逐字保留。
- **引用与引文格式**：编号、作者-年份、脚注，一律不动。
- **中文语感成分**：必要的助词、结构助词、限定词、承接连词（若其承担句法/限定功能）。
  润色目标是“不空泛”，不是“越短越好”；删完读起来像翻译腔或电报体就是改坏了。

## 五、主张-证据纪律（润色的硬约束）

对每个论断做下面四件事之一：

1. **无支撑 → 加证据指针或降级。**
   *改前*：本方法更稳健。 *改后*：在分布偏移下本方法准确率下降 2 个百分点，对照方法下降 11 个（图 3）。
2. **动词强于证据 → 降级。**
   *改前*：这证明了本方法普遍更优。 *改后*：在这三个数据集上，本方法与最强基线相当或更优（表 2）。
3. **模糊量级 → 数值或区间 + 对照 + 指标。**
   *改前*：提升明显。 *改后*：平衡准确率较最强基线提高 2–6 个百分点。
   优先给区间而非单个均值；注明是相对哪个基线、哪个指标、哪种平均方式。
4. **比较对象选最强基线**，不要拿弱基线衬托；p、95%CI、效应量、样本量原样引用，不改写数值写法。

另外三条本领域红线：
- **相关 ≠ 因果**：观察性数据只能写“与……相关/提示”，不写“导致/改善”。
- **动物/体外 ≠ 人体**：证据级别必须在句子里写清（本课题的 PBM 证据尤其如此）。
- **方案/标书里的“预期”≠“结果”**：未完成的数据不得写成已完成。

## 六、英文稿模式（英文摘要/正文/审稿回复）

**英文稿优先加载技能 `academic-humanizer-en`（上游原文原样，六层规则与例子更全）；若只加载了本技能，
处理英文稿前必须先 read 本技能目录 `references/academic-humanizer-en.md`，以那份为准；本节是快速清单，不替代原文。**
英文任务同时保留第四、五节的纪律，并额外查下列英文 tell：

- 空泛开场：*In recent years, X has attracted increasing attention* / *With the rapid development of...*。
- 拔高：*paves the way for*、*a crucial step toward*、*has the potential to revolutionize*、
  *sheds light on*、*bridges the gap*、*of paramount importance*。
- 过度声称：*demonstrate/prove/establish*（经验研究用 show/provide evidence）、无检验的 *significantly*。
- 空强调：*extensive/comprehensive/thorough experiments*、*a wide range of*、*numerous*。
- 新意堆砌：*novel* 一节出现多次、*to the best of our knowledge*、*for the first time*。
- 连接词三连：*Moreover/Furthermore/Additionally* 连续起句。
- AI 高频词：*delve, underscore, intricate, tapestry, testament, pivotal, showcase, foster,
  leverage（作填充）, realm, seamless, landscape（抽象义）*。
- 系动词回避（*serves as* → *is*）、否定平行（*not just X, but Y*）、三元排比、超长堆叠从句。
- **em-dash 一律去掉**（改逗号、冒号、括号或分句）。
- 保留：证据限定（suggest/is consistent with）、合适的被动、第一人称 we、术语与符号。

英文原文全文与 before/after 例子见本技能目录 `references/academic-humanizer-en.md`、
`references/before-after-en.md`（MIT 许可，来自 AIScientists-Dev/academic-humanizer）。

## 七、基金 / 研究方案模式

**核心差别**：论文卖“已完成的结果”，标书卖“愿景 + 可行性”。愿景语（长期目标、变革性、
开创性）在这里是**合适的**，不要按论文模式删平；要换一套纪律：**主张 ↔ 可行性**。

**中国常见场景（博士课题方案、国自然/省级课题、伦理/注册材料）**：
- 立项依据：现状与缺口要具体（数字、指南、既往研究结论），不要“具有重要意义”。
- 科学问题/假说：一句可证伪的承诺，不要“探讨是否可能”。
- 研究内容与方案：可复现（人群、干预参数、对照、终点、时点、统计）；与 SPIRIT/CONSORT 一致。
- 可行性：前期数据、方法学基础、团队与平台、设备与伦理通道——放在前面作为“可执行”的证据。
- 创新点：写具体差异（与哪条既往路线相比、解决了哪个缺口），不写“填补空白”。
- 预期成果：区分“预期”与“已获得”；不编前期结果、合作单位、基金号、伦理批件。

**NSF / NIH（英文标书）要点**：
- NSF Project Summary 一页三块：Overview / Intellectual Merit / Broader Impacts，各自自足。
- NIH Specific Aims 一页即全案：问题与缺口 → 长期目标与中心假说（可证伪）→
  “The objective of this application is...” → 2–3 个平行、可独立成立的 Aim（目标+方法一句+预期结果）
  → 成功后的 payoff。
- 前 1–3 页决定评分：hook、gap、central idea、aims、payoff 必须在前几页出现；后面再改救不回来。
- 每个大胆论断都要有“立足点”（预实验、既往结果、经典理论、合作方），否则降级或补证据。
- Aim 不要串行依赖（Aim 2 挂在 Aim 1 上会被判脆弱）；确有依赖就写失败回退方案。

## 八、与本机/本项目技能的配合

- 需要**结构/报告规范**（IMRaD、CONSORT、STROBE、PRISMA）→ 配合 `paper-writing`。
- 需要**方案条目/一致性**（SPIRIT）→ 配合 `protocol-spirit`。
- 需要**领域证据边界**（PBM 剂量、动物 vs 人体）→ 配合 `pbm-osteoporosis`。
- 需要**统计表述/样本量**→ 配合 `stats-plan`；成稿导出 Word → `docx-toolkit`。
- 本技能只做**文风与主张-证据**这一层；不替代上述任何一项，也不替作者下科学判断。

**本机操作约束**：用 read/edit 原子改文本（改前先读、大稿分批 1–2 节）；文本处理可用 python 工具；
不要安装依赖、不要调用 pandoc/LibreOffice；改完用 grep 核对数字/引用清单未变。

## 九、输出格式

1. **审校表**：位置 | 原句摘录 | 类型（C1/E4…） | 建议改法 | 证据状态。只列真正影响质量的，不逐词罗列。
2. **润色稿**：完整段落（保持原编号、图表引用位置）；不改动的地方不重排。
3. **改动说明**：删了哪些模式、哪些论断降级/补了证据指针、文风与期刊匹配说明。
4. **待作者确认**（若有）：疑似数据/引用/结论问题，只列不改。

## 十、禁止事项

- 增删数据、公式、图表号、引用；编造文献或前期结果；改结论方向或统计显著性表述。
- 为“像人”而口语化、加情绪/金句/表情；为“简洁”删掉限定词导致过度声称。
- 整篇推倒重写（易造成引用错位）；一次改全文超过 2 节（难以核对）。
- 把相关写成因果、把动物/体外写成人体、把方案写成已完成。
- 用于规避 AI 使用披露或检测。
